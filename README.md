## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named exactly `PeterKaramwinBanyen.github.io`.
2. Extract this ZIP on your computer.
3. Upload the contents of the extracted `PeterKaramwinBanyen-Portfolio-Website` folder to the **root** of that repository. The `index.html` file must be at the repository root, not inside another folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your site should be available at `https://PeterKaramwinBanyen.github.io`.

## Updating the website
Edit `index.html` to update text and links. Place new images in `assets/images/` or `assets/projects/` and reference them with relative paths. Keep filenames simple and avoid spaces.

## Important before public launch
- Confirm that TDC Ghana Ltd permits public description of the digitization workflow. The site intentionally uses an illustrative dashboard graphic instead of publishing the internal workbook or operational figures.
- The independent SQL examples use demo data; do not upload actual client records, database exports, credentials, server names or screenshots containing confidential details.
- Review the CV and contact details before publishing.
- LinkedIn and GitHub are linked directly. Instagram and TikTok sharing is available through the device/browser share control; add personal profile URLs only if you want them displayed.
- The site is static and does not collect visitor data or use a contact form. Visitors can email or call you directly.

## Local preview
Open `index.html` in a browser. For a local server, run `python -m http.server 8000` from the folder and visit `http://localhost:8000`.
